# Architecture

## Stack

| Layer | Technology | Notes |
|-------|-----------|-------|
| Runtime | Node.js (LTS) | Hostinger Node.js hosting |
| Process manager | Phusion Passenger | `process.env.PORT \|\| 3000`; no PM2 |
| Framework | Express 4 | |
| Templates | EJS + express-ejs-layouts | layout at `views/layouts/main.ejs` |
| Dev database | SQLite (better-sqlite3) | zero-config; `DB_DRIVER=sqlite` |
| Prod database | MySQL (mysql2/promise) | `DB_DRIVER=mysql` |
| Sessions | express-session | MemoryStore (dev); MySQLStore (prod) |
| Cache | node-cache (in-process) | rebuilt on demand after restart |
| Static cache | `public/cache/*.json` | generated by `scripts/generate-ruleset-cache.js` |
| Email | Nodemailer | console transport (dev); SMTP (prod) |
| Scheduling | node-cron | in-process; daily/weekly tasks |
| Frontend | Alpine.js (CDN) + vanilla JS | no build step |
| Validation | Zod | server-side only |
| Auth | bcryptjs + express-session | custom; no Passport |
| CSRF | Custom session-based | `middleware/csrfProtection.js` |

## Request lifecycle

```
Browser → Passenger → Express
  → rateLimiter
  → session
  → flash
  → gpcSignal (reads Sec-GPC header)
  → csrfProtection (validates on mutating methods)
  → template locals injected (currentUser, csrfToken, flash)
  → route handler
  → model (DB query)
  → render EJS / JSON response
```

## Caching tiers

1. **HTTP headers** — `Cache-Control: public, max-age=3600` on static assets
2. **node-cache** — ruleset (1 hr TTL), team validation results (10 min TTL), blocked phrases (15 min TTL)
3. **Disk JSON** — `public/cache/ruleset-validator.json` served statically; refreshed on ruleset publish

## Database abstraction

`config/database.js` exposes `db.all()`, `db.get()`, `db.run()` over both SQLite and MySQL.
Switch with `DB_DRIVER` env var (default: `sqlite`).

## Environment variables

See `.env.example` for the full list. Key vars:

| Var | Default | Purpose |
|-----|---------|---------|
| `DB_DRIVER` | `sqlite` | `sqlite` or `mysql` |
| `SESSION_SECRET` | required | express-session secret |
| `EMAIL_DRIVER` | `console` | `console` or `smtp` |
| `SITE_URL` | `http://localhost:3000` | Base URL for email links |
| `NODE_ENV` | `development` | `production` enables MySQLStore |

## Hostinger notes

- Entry point: `server.js` (Passenger looks for `app.js` or `server.js`)
- Environment variables set via hPanel → Node.js → Environment Variables
- No write access to `node_modules`; all deps must be in `package.json`
- Passenger restarts on file change in production; sessions survive via MySQLStore
